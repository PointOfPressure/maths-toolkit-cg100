# AQA Maths + MEI Further Maths fusion

Date: 2026-09-23. Built on the `aqa` branch. Extends
`2026-09-15-aqa-rebuild-design.md`, which still holds for everything below
except the Further tree.

## Why

The student sits **AQA 7357** for A-level Mathematics and **OCR B (MEI)
H645** for Further Mathematics. The `aqa` branch mapped both to AQA (7357 +
7367). `main` mapped both to MEI (H640 + H645) on the old UI. This build uses
the `aqa` engine, UI and module contract for both qualifications, keeps the
Maths tree AQA, and rebuilds the Further tree on MEI H645.

## Tree

Home: `Calculate`, `CAS f(x)`, `Maths AQA 7357`, `Further MEI H645`,
`Formulae AQA`, `Angle`.

- Maths: Home > section > tool, unchanged (`mpure`, `mcalc`, `mstat`, `mmech`).
- Further: Home > **paper** > section > tool. `casui.FURTHER` is a tuple of
  `(paper title, modules)`:

| Paper | Modules |
|---|---|
| Core Pure Y420 (mandatory) | `fcore`, `fcalc` |
| Mechanics Major Y421 / Minor Y431 | `fmech` |
| Statistics Major Y422 / Minor Y432 | `fstat` |
| Modelling with Algorithms Y433 | `falgo` |
| Numerical Methods Y434 | `fnum` |
| Extra Pure Y435 | `fxpure` |
| Further Pure with Technology Y436 | `ffpt` |

Each minor option is a subset of the matching major, so one module serves
both; section comments mark Major-only statements.

## Coverage source

`docs/spec-h645.txt` lists every H645 content statement by paper, taken from
the OCR specification (Version 2.1, March 2026) via the audit on `main`.
Tools that served only an AQA 7367 statement were dropped: conics,
reduction formulae, surface area, rational-inequality solvers, the
exponential distribution, Type I/II errors, Poisson and one-sample t
hypothesis tests (t intervals stay), and Yates' correction. Tools that
exist in AQA 7367 but sit in a different MEI paper moved there. Eigenvectors and diagonalisation went to
Extra Pure, numerical integration to Numerical Methods, and arc length to
Pure with Technology. MEI-only content (algorithms, number theory, groups,
recurrence relations, Wilcoxon, Spearman, and so on) was ported from `main`'s
modules onto the new contract.

## Formulae

The on-device booklet is AQA's, which is the correct one for 7357. The MEI
H645 "Formulae and Statistical Tables" booklet is not included: it could not
be fetched when this was built, and it is not typed from memory.

## Critical values

Nothing is typed from memory. Wilcoxon signed-rank critical values are
counted exactly (subset-sum DP, n <= 50, Normal approximation beyond).
Spearman critical values are an exact table for n = 4..20 generated by
enumeration; for n >= 13 some entries differ from the old `main` table, so
check one against the MEI booklet. Outside the tables the t-approximation is
used and flagged on screen.

## Conventions to confirm against MEI teaching

- Critical path: interfering float = total float - independent float.
- Y436 RK2: the comparison tool uses Heun's form; a separate midpoint tool
  covers the other.

## Shared changes made for the fusion

- `plot.run(kind='lines')`: polylines, one colour per list, `None` breaks.
  Used by the cobweb, error-vs-h, contour and tangent-field plots.
- `fmt` prints `1/2+i/2`, not `1/2+1i/2`, and snaps `1.0000000000000002j`.
- `caseng.evalf` sends int^int with exponent > 64 through float, so huge
  exact powers overflow cleanly instead of stalling.

## Not verified on hardware

Tested on PC only (tests, stress, devlint, casioshot). Opening Core Pure
imports `fcore` + `fcalc` (~137 KB source); the `aqa` build imported all four
7367 modules at once, so this should be no worse, but it has not been run on
the calculator.
